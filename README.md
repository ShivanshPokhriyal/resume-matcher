# 🚀 AI Resume Matcher

An AI-powered Resume Matcher built with **Streamlit** and **Groq Llama 3.1** that compares a resume against a job description and provides detailed recruiter-style feedback.

## 🌐 Live Demo

👉 https://shivanshpokhriyal-resume-matcher.streamlit.app/

---

## ✨ Features

- Compare resume with a job description
- AI-powered analysis using Groq Llama 3.1
- Match strengths and weaknesses
- Missing skills identification
- Improvement suggestions
- Clean Streamlit interface

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ShivanshPokhriyal/resume-matcher.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=your_api_key
```

Run the app

```bash
streamlit run app.py
```
